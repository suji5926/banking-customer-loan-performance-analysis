
# Banking Customer & Loan Performance Analysis

## Project Overview

This project explores banking customer and loan data to understand lending activity, loan distribution, repayment behavior and default-related metrics.

The goal is to organize customer and loan information, perform structured SQL analysis and present useful performance indicators through dashboards that support data-driven interpretation.

## Business Objectives

- Measure overall loan volume and total loan amount.
- Explore how loans are distributed across relevant customer and loan segments.
- Examine repayment patterns and default-related indicators.
- Compare lending performance across available categories.
- Present important banking metrics through clear visualizations.

## Tools & Technologies

- **Microsoft Excel:** Data inspection, cleaning, validation and PivotTable analysis.
- **SQL:** Aggregations, joins, filtering, grouping and business analysis.
- **Power BI:** Dashboard development and visual exploration of performance metrics.

## Project Workflow

1. **Data preparation:** Inspected customer and branch data, checked duplicates and missing values, and reviewed data types.
2. **Excel analysis:** Used PivotTables and summaries to explore customer and loan characteristics.
3. **SQL analysis:** Developed 15 analytical queries to calculate loan metrics and investigate banking performance.
4. **Dashboard development:** Organized relevant metrics and comparisons into dashboard views.
5. **Business interpretation:** Reviewed the results to understand lending activity, repayment patterns and default-related measures.

## Key Findings

The SQL summary produced the following overall metrics:

- **Total loans:** 20,500
- **Total loan amount:** 26,174,010,000, in the dataset's monetary units

These are overall summary metrics, not evidence of a particular default rate or repayment trend. More detailed findings should be added from the corresponding query outputs and dashboard results.

## Analysis Areas

- Total loan volume and loan amount
- Customer and loan distribution
- Repayment-related metrics
- Default-related indicators
- Comparisons across available customer, branch or loan categories

## Project Files

The repository contains the analysis files uploaded for this project. Refer to the individual files for the available dataset, SQL work, notebooks and dashboard artifacts.

## Skills Demonstrated

Data cleaning, Excel PivotTables, SQL querying, aggregation, data validation, banking metric analysis, dashboard design and business interpretation.

## Conclusion

This project demonstrates how customer and loan data can be prepared, analyzed and visualized to provide a clearer view of lending activity and loan performance.
